# MXStyleMediaPlayer - Full Feature Build

This repository is a substantially expanded MX-style Android media-player foundation using Kotlin + Media3.

Implemented in this build:
- Local video library from MediaStore
- Video list with duration and file size
- Media3/ExoPlayer playback
- Play/pause
- ±10 second seeking
- Playback speed: 1x/1.25x/1.5x/2x
- Screen lock control
- Fullscreen/orientation control
- Swipe seek gestures
- Left-side brightness gesture
- Right-side volume gesture
- Keep-screen-on playback
- Android media permissions
- GitHub Actions APK build
- Developer About information
